Start here for frontend tasks after reading the root [`AGENTS.md`](../../AGENTS.md). Use this index to select only the documentation relevant to the task; inspect source when documentation is incomplete or may be outdated.

## Context-efficient workflow

1. Read `AGENTS.md` and this index.
2. Select only the relevant documents above.
3. Search for existing components/utilities and inspect only relevant frontend source.
4. Verify claims against current code; documentation is not a substitute for source inspection.
5. After significant frontend work, update only affected documents and add a concise task-log entry.

All documentation here is frontend-only. Backend and database implementation are out of scope.
