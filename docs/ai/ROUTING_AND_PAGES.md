# Routing and Pages

The application uses the Next.js App Router. Parenthesized route groups organize files but do not appear in the URL.

| URL | Page file | Current responsibility/state |
|---|---|---|
| `/` | `src/app/page.tsx` | Composes the home section components in reference order: hero and service strip, `Popular Categories`, `New Trends`, `Featured Products`, collection banners, `Flash Sale`, `Trending Now`, and `Top Brand Products`. Product content is UI sample data; no catalog API is connected. |
| `/cart` | `src/app/cart/page.tsx` | Displays products from the shared browser-local cart, supports quantity updates and item removal, and links to checkout for the full cart. Cart contents are not account-synced. |
| `/checkout` | `src/app/checkout/page.tsx` | Guest checkout for either the current cart or one product via `?product=<slug>&quantity=<n>`. Collects delivery contact/address details and uses cash on delivery. Orders are saved in this browser only; there is no server submission, delivery-fee calculation, or payment processing. |
| `/order-confirmation` | `src/app/order-confirmation/page.tsx` | Reads the locally saved order by `orderId` and displays its items and delivery details. The confirmation explicitly indicates that the store has not received the demo order. |
| `/delivery` | `src/app/delivery/page.tsx` | Static “Careful delivery” storefront information page linked from the footer, describing packing, delivery details, and cash-on-delivery arrival. |
| `/genuine-products` | `src/app/genuine-products/page.tsx` | Static storefront guide linked from the footer, with practical checks for product details, packaging, invoices, and item-specific warranty terms. |
| `/products` | `src/app/products/page.tsx` | Shared all-products/category listing. `category` and `parent` select a listing; filter values, min/max price, `sort`, and `page` are synchronized with the URL. The client filters the local sample catalog and renders category-specific controls from shared catalog metadata; no product API is connected. |
| `/products/[slug]` | `src/app/products/[slug]/page.tsx` | Shared details route for every distinct product in the local storefront sample data. `generateStaticParams` creates a page per sample product; URL param access is contained in a Suspense boundary with a loading fallback, and unknown slugs return not found. The HP Pavilion has extra sample images and specifications; other products show the available name, category, image, and pricing. Add to Cart saves the product in the shared browser-local cart; Buy Now goes directly to checkout for that product and quantity. No product or order API is connected. |
| `/login` | `src/app/(auth)/login/page.tsx` | Sign-in form preview with links to registration and password recovery; authentication submission is not connected. |
| `/register` | `src/app/(auth)/register/page.tsx` | Registration form navigates to `/verify-otp` with the entered email after browser validation. |
| `/forgot-password` | `src/app/(auth)/forgot-password/page.tsx` | Recovery form navigates to `/verify-otp` with the entered email and password-reset flow. |
| `/verify-otp` | `src/app/(auth)/verify-otp/page.tsx` | Six-digit code form displays the supplied email; Continue navigates to login for signup or reset-password for recovery. |
| `/reset-password` | `src/app/(auth)/reset-password/page.tsx` | New password form checks confirmation and navigates to login. |
| `/account` | `src/app/(user)/account/page.tsx` | Placeholder that returns `null`. |
| `/dashboard` | `src/app/(admin)/dashboard/page.tsx` | Responsive admin shell with reusable sidebar, KPI cards, recent-order search/table, six-month revenue chart, and top categories. Orders and revenue are derived from browser-local demo orders; product count comes from the local sample catalog. |
| `/dashboard/products` | `src/app/(admin)/dashboard/products/page.tsx` | Product management demo with search/category/stock filters, sorting, pagination, CSV export, and browser-local add/edit/delete and publish-status controls. Changes do not update the storefront or a server. |
| `/dashboard/inventory` | `src/app/(admin)/dashboard/inventory/page.tsx` | Sample inventory summary, low-stock alerts, filters, pagination, and browser-local stock adjustment. Seed quantities and changes are not server-synced. |

Storefront routes inherit `src/app/layout.tsx`, which imports `globals.css` and renders the global `Navbar` before route content and global `Footer` after it. `/dashboard` and its nested routes use the responsive admin shell without the storefront chrome. The Navbar cart panel links to `/cart`. The category mega-menu and Popular Categories links navigate to `/products` with the selected category in the query string. There are no nested route layouts. `src/app/favicon.ico` is present.

All authentication pages are visitable through their direct URLs and cross-links. Registration/recovery flows support client-side demo navigation and browser-side field validation only; they do not create accounts, send email, verify codes, or update passwords. Product cards and related-product rows link to the shared slug-based product details route. Cart additions and edits and demo order records persist in browser `localStorage`; listing, cart, and checkout behavior use local sample data and are not connected to product, order, payment, or delivery APIs.
